# TH QA LAB — 로그인 기능 QA 통합 포트폴리오

가상 Flask 로그인 기능에 대한 요구사항 분석, 테스트 설계, 테스트 수행 기록을 공개하는 GitHub Pages 정적 사이트입니다.

## 이번 버전
- 로그인 QA 상세 페이지: `projects/login-qa/index.html`
- 요구사항 분석서 추가 확인 12건을 웹에서 검색·열람
- 테스트 케이스 TC-001~043 전체 검색·필터·상세 열람
- 요구사항 REQ-001~010과 연결 TC 추적표
- DOCX/XLSX 원본 4개, 명세서 PDF 2개 다운로드·열람
- 자동화 프로젝트는 별도 작업이므로 아직 추가하지 않음

## GitHub Pages 게시
1. 압축을 풀고 **폴더 내부 전체 파일과 폴더**를 저장소 루트에 업로드합니다.
2. `index.html`, `styles.css`, `projects.js`, `app.js`와 `projects/login-qa/`의 경로를 유지합니다.
3. GitHub Pages가 `main` / `(root)`에서 배포하도록 합니다.
4. GitHub Actions의 Pages 배포 성공 후 `https://phixia0.github.io/projects/login-qa/`을 방문합니다.

## 출처와 유의점
웹에서 보여주는 분석·TC 세부 내용은 함께 첨부한 XLSX 원본 파일의 셀 데이터를 정적 JS 데이터 파일로 변환한 것입니다. 웹 페이지에서 수정해도 원본 문서는 변경되지 않습니다. **실제 운영 서비스 또는 현업 수행 사례가 아닌 학습용 가상 서비스 프로젝트**입니다. 제출 기록의 Pass는 독립적인 재실행 검증이 아닙니다. 원본 문서에 있는 테스트용 계정과 비밀번호는 공개용 가상 데이터여야 합니다.
